## [0.1.0-beta.1]

First beta. Tried so far on one phone (Samsung Galaxy S23, Android 17); expect rough edges.

- Mirror and control an Android phone from the Mac, with hardware video decoding and audio.
- Normal, Gaming and Developer modes with a customizable control rail (horizontal for landscape pictures).
- Game keymaps with an editor, macros, rapid tap, swipe and game controller bindings.
- Copy files from the Mac and paste them into phone apps such as WhatsApp.
- Stream to OBS locally, Stream Mode, screen recording, GIF export and screenshots.
- Developer tools: Logcat, UI inspector, performance HUD, quick toggles with network speed profiles, API log and database viewer.
- Look inside a debug app to see the contents of its HTTP and HTTPS calls (uses the profiler from your own Android Studio).
- Wireless setup, multiple phones, Mini Mirror, closing the window disconnects while the app stays in the Dock.
- Editable menu shortcuts, choosable adb program, and 13 languages with English as the fallback.
